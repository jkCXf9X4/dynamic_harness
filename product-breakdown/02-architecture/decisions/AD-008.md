# AD-008: Comms Layer = Swappable Routing Backend Behind One Uniform Tool Surface

## Status
Accepted

## Layer
Verification (verification-led design; the design lives in the verification
investigation that produced it)

## Context
The verified baseline is **one implicit router**: `converse` reaches any agent
by ID (`get_other_agent` → `runtime.get_agent`), gated only by target status —
no parent-mediation gate, no sibling-scope gate, no mailbox, no topic registry.
The four topology cells (parent-mediated, same-parent siblings, one shared
channel, topic channels) cannot be toggled today; they must be *constructed*.
The comms work was measurement-first ("verification-led design"), documented in
`04-verification/communication-structures/` (INVESTIGATION, PLAN, design).

## Decision
Build a **thin, host-agnostic communication layer** between the tools and the
runtime so the four topology cells are a **config switch — not a refactor**. It
exposes **ONE uniform tool surface** (`converse` / `message` / `post` /
`channel_read` / `subscribe` / `unsubscribe` / `channels` / `channel_info`);
**only the routing backend differs per cell** (one config key or one
`Runtime(comms=...)` argument), mirroring `core/policies/` decision/execution.

Shape: `core/comms/` — `message.py` (CommsMessage), `backend.py` (CommsBackend:
route_message / post / subscribe / unsubscribe / read / channels / channel_info;
per-(agent, topic) watermarks, backend-owned), `channel.py` (ChannelPolicy),
`digest.py` (CommsDigestPolicy), `backends/` (relay, siblings, shared, topics),
`factory.py` (build_backend — the switching seam); tool defs in `core/tools/comms.py`.

## Alternatives Considered
- **One implicit router (status quo)** — REJECTED for the experiment: the four
  topologies cannot be toggled; a swappable layer is the cheapest construction.
- **Four separate tool surfaces (one per topology)** — REJECTED: the model would
  learn a new vocabulary per cell; the point is one vocabulary with the backend
  deciding who receives what.
- **Design reasoning alone (no measurement)** — REJECTED: success criterion 4 —
  "A topology (or the hybrid) is adopted on evidence, not on the dev
  investigation's design reasoning alone."

## Consequences
**Positive:** the tools an agent calls never change between cells; P0 (backends)
+ P1 (tool surface + config switching) + P2 (push-digest policy) + P3
(collaboration bed) are **implemented**; P4 (real-LLM, 2026-09-18) ran once —
`off` deadlocked (0 turns), `shared` completed correctly (40 turns / 389s /
~0.8M tokens), `topics_parent` completed with ~6× churn (232 turns / 5.2M
tokens / 765s); mock-first determinism makes the bed reproducible; the deadlock
mechanism is understood (blocking `converse` acquires the target's `_loop_lock`
and runs the whole re-run; channel topologies are robust).

**Negative:** P4 is n=1 per cell, pricing unconfigured (cost $0), interrupted
once by a kill — treat ratios, not absolutes, as signal (IMP-001); the
`topics_parent` churn hypothesis is untested; a lock-safe `converse` is out of scope.
