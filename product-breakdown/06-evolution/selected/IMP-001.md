## Lifecycle Stage

## Status

## Theme
Firm up the communication-topology comparison by running more than one replicate per cell.

## Evidence
- `../../04-verification/communication-structures/RESULTS.md`: "Cells: 3 · Task modes: interdependent · Replicates: 1"; per cell n=1 — `off` (timed_out, 0 turns, 900s), `shared` (completed, correct, 40 turns, 389.3s, 799,955 tokens), `topics_parent` (completed, correct, 232 turns, 764.5s, 5,219,622 tokens).
- `.../metrics-cells.json`: raw per-cell data (`off#rep0`, `shared#rep0`, `topics_parent#rep0`).
- `.../FINDINGS.md`: "Caveat: n=1 per cell, pricing unconfigured (cost $0)… treat the ratios, not the absolutes, as signal." Next hypothesis: the parent-declared channel set (`findings`) plus per-topic watermarks drove extra verification/topic-policing or repeated `channel_read` polling; a bigger replicate budget + per-tool turn breakdown would separate LLM verbosity from harness overhead.

## Current Pain Or Risk
The key collaboration decisions (AD-001 reject parent-mediated relaying; AD-003 workspace-primary) rest on a single replicate per cell. The `shared`-vs-`topics_parent` ~6× churn is a hypothesis, not a measurement; the `off` deadlock is confirmed twice, but other cells' numbers could shift. A future run could re-search this design space or adopt a topology on noise.

## Proposed Improvement
Run the P4 real-LLM battery with multiple replicates per cell (e.g. n=3–5) on the interdependent collab task, plus a per-tool turn breakdown from the traces to separate LLM verbosity from harness overhead. Report mean + spread per cell in RESULTS.md / metrics-cells.json; keep the watchdog and mock-first determinism bed unchanged.

## Risk And Blast Radius
Low. Cost: real-LLM tokens per run (`topics_parent` alone ~5.2M tokens in one run; pricing was unconfigured at $0.00). Blast radius: the verification layer and the AD-001/AD-003 evidence base; no runtime code changes. Risk: churn may prove harness overhead, reopening the AD-002/AD-004 channel design — the point of measuring.
